คู่มือการลองใช้ model
โครงงาน Awakening of the Gyroscope (โมเดลจำแนกกิจกรรมจากชุดข้อมูล Kaggle)
สำหรับเครื่อง Windows

ทำตามลำดับพาร์ท 1 ถึง 5 พาร์ท 1-3 ทำครั้งเดียวต่อเครื่อง
ถ้าติดปัญหาให้ดูพาร์ท 6


==================================================
พาร์ท 0  ไฟล์ที่ต้องมี
==================================================

ดาวน์โหลดโฟลเดอร์โปรเจกต์จาก repo มาไว้ในเครื่อง
(git clone หรือกด Download ZIP แล้วแตกไฟล์)

ในโฟลเดอร์ต้องมี 3 ไฟล์นี้อยู่ด้วยกัน

  Awakening_of_the_Gyroscope_Kaggle.ipynb   ไฟล์โมเดล (notebook)
  train.csv                                 ข้อมูลสำหรับสร้างโมเดล 7,352 แถว
  test.csv                                  ข้อมูลสำหรับทดสอบ 2,947 แถว

ถ้าขาดไฟล์ csv ไฟล์ใดไฟล์หนึ่ง จะรันไม่ได้


==================================================
พาร์ท 1  ติดตั้ง Python
==================================================

1. เข้าเว็บ https://www.python.org/downloads/
2. ดาวน์โหลดตัวติดตั้งสำหรับ Windows แล้วเปิดไฟล์ที่โหลดมา
3. ถ้าหน้าติดตั้งมีช่อง "Add python.exe to PATH" ให้ติ๊กช่องนี้ก่อน
4. กดติดตั้งจนเสร็จ

ตรวจว่าติดตั้งสำเร็จ
1. กดปุ่ม Windows พิมพ์ cmd แล้วกด Enter จะได้หน้าต่าง Command Prompt
2. พิมพ์คำสั่งนี้แล้วกด Enter

     py --version

   ถ้าขึ้นเลขเวอร์ชัน เช่น Python 3.14.x แปลว่าใช้ได้
   (โมเดลนี้ทดสอบแล้วกับ Python 3.13 และ 3.14)


==================================================
พาร์ท 2  ติดตั้ง VS Code และ kernel
==================================================

kernel คือตัวที่รับโค้ดใน notebook ไปรันด้วย Python
ต้องมี 2 อย่าง คือ ส่วนขยายใน VS Code (พาร์ทนี้) และ ipykernel (พาร์ท 3)

1. เข้าเว็บ https://code.visualstudio.com/ ดาวน์โหลดและติดตั้ง VS Code
2. เปิด VS Code แล้วกด Ctrl + Shift + X เพื่อเปิดหน้า Extensions
3. พิมพ์ Python ในช่องค้นหา เลือกตัวที่ผู้พัฒนาคือ Microsoft แล้วกด Install
4. พิมพ์ Jupyter ในช่องค้นหา เลือกตัวที่ผู้พัฒนาคือ Microsoft แล้วกด Install


==================================================
พาร์ท 3  ติดตั้งไลบรารีที่ต้องใช้
==================================================

ไลบรารีที่ใช้มี 4 ตัว

  numpy        คำนวณเวกเตอร์และเมทริกซ์
  pandas       อ่านไฟล์ csv
  matplotlib   วาดกราฟ
  ipykernel    ทำให้ Python ตัวนี้ใช้เป็น kernel ของ notebook ได้

วิธีติดตั้ง
1. เปิด Command Prompt (กดปุ่ม Windows พิมพ์ cmd แล้วกด Enter)
2. พิมพ์คำสั่งนี้แล้วกด Enter รอจนเสร็จ

     py -m pip install numpy pandas matplotlib ipykernel

   ถ้าขึ้นว่าไม่รู้จักคำสั่ง py ให้ใช้คำสั่งนี้แทน

     python -m pip install numpy pandas matplotlib ipykernel

ติดตั้งสำเร็จเมื่อบรรทัดท้าย ๆ ขึ้นว่า Successfully installed ...


==================================================
พาร์ท 4  เปิดและรันโมเดล
==================================================

1. เปิด VS Code ไปที่เมนู File > Open Folder แล้วเลือกโฟลเดอร์โปรเจกต์
   (ให้เปิดทั้งโฟลเดอร์ ไม่ใช่เปิดไฟล์ notebook ไฟล์เดียว)
2. ถ้ามีหน้าต่างถามว่า "Do you trust the authors of the files in this folder?"
   ให้กด Yes, I trust the authors
3. ที่แถบด้านซ้าย คลิกไฟล์ Awakening_of_the_Gyroscope_Kaggle.ipynb
4. กด Select Kernel ที่มุมขวาบน เลือก Python Environments
   แล้วเลือก Python ตัวที่ติดตั้งในพาร์ท 1
5. กด Run All ที่แถบเครื่องมือด้านบนของ notebook แล้วรอประมาณ 10-30 วินาที

ผลที่ควรได้
  - เซลล์โค้ดแรกพิมพ์   train: (7352, 561)  และ  test:  (2947, 561)
  - ส่วนเลือกจำนวนแกนพิมพ์   k = 67
  - ส่วนผลลัพธ์พิมพ์   Accuracy = 84.15%
  - มีกราฟ 3 รูป และชื่อกิจกรรมเป็นภาษาไทย

ถ้าได้ตามนี้ แปลว่าเครื่องพร้อมใช้งานแล้ว

หมายเหตุ: เปิดไฟล์ครั้งแรกจะเห็นผลลัพธ์และกราฟอยู่แล้วโดยยังไม่ต้องรัน
เพราะผลจากการรันครั้งก่อนถูกบันทึกไว้ในไฟล์ การกด Run All คือการคำนวณใหม่บนเครื่องตัวเอง


==================================================
พาร์ท 5  ลองทำนายทีละแถว
==================================================

ต้องกด Run All ตามพาร์ท 4 ให้ผ่านก่อนหนึ่งครั้ง

1. เลื่อนลงไปล่างสุดของ notebook ที่หัวข้อ "การทำนายข้อมูลทีละแถว"
2. หาเซลล์ที่มีบรรทัด   show_row(...)   ซึ่งมีตัวเลขอยู่ในวงเล็บ
3. แก้ตัวเลขในวงเล็บเป็นแถวที่ต้องการ ใส่ได้ตั้งแต่ 1 ถึง 2947
4. คลิกในเซลล์นั้น แล้วกด Shift + Enter

ผลที่แสดงมี 3 ส่วน
  - ระยะจากข้อมูลแถวนั้นไปยัง centroid ของทั้ง 6 กิจกรรม
  - กิจกรรมที่โมเดลทำนาย (กิจกรรมที่ระยะน้อยที่สุด)
  - กิจกรรมจริง และบอกว่าทำนายถูกหรือผิด

เลขแถวนับเฉพาะแถวข้อมูลของ test.csv ไม่นับแถวหัวตาราง และเริ่มนับจาก 1

ช่วงแถวของแต่ละกิจกรรม (ชุดแรกของไฟล์)

  ยืน          แถวที่ 1 ถึง 31
  นั่ง          แถวที่ 32 ถึง 55
  นอน          แถวที่ 56 ถึง 79
  เดิน          แถวที่ 80 ถึง 109
  ลงบันได      แถวที่ 110 ถึง 133
  ขึ้นบันได      แถวที่ 134 ถึง 158

หลังแถวที่ 158 ลำดับเดิมวนซ้ำไปจนถึงแถวที่ 2947 ช่วงละประมาณ 20-30 แถว

พาร์ท 6  ปัญหาที่พบบ่อย
==================================================

อาการ: ขึ้น ModuleNotFoundError: No module named 'numpy' (หรือชื่อไลบรารีอื่น)
สาเหตุ: Python ที่เลือกเป็น kernel ยังไม่มีไลบรารีนั้น มักเกิดเมื่อเครื่องมี Python หลายตัว
วิธีแก้: กด + Code เพื่อเพิ่มเซลล์ใหม่ใน notebook พิมพ์บรรทัดนี้แล้วกด Shift + Enter

     %pip install numpy pandas matplotlib

  รอจนเสร็จ กด Restart ที่แถบเครื่องมือ แล้วกด Run All ใหม่
  จากนั้นลบเซลล์ที่เพิ่มไว้ได้

อาการ: ขึ้น FileNotFoundError เกี่ยวกับ train.csv หรือ test.csv
สาเหตุ: ไฟล์ csv ไม่ได้อยู่ในโฟลเดอร์เดียวกับ notebook หรือเปิดไฟล์ notebook ไฟล์เดียว
วิธีแก้: ตรวจไฟล์ตามพาร์ท 0 แล้วเปิดด้วย File > Open Folder ตามพาร์ท 4

อาการ: กด Shift + Enter หรือ Run All แล้วไม่มีอะไรเกิดขึ้น
สาเหตุ: ยังไม่ได้เลือก kernel (มุมขวาบนยังเขียนว่า Select Kernel)
วิธีแก้: ทำพาร์ท 4 ข้อ 4

อาการ: กด Select Kernel แล้วไม่มี Python ให้เลือก
สาเหตุ: ยังไม่ได้ติดตั้ง Python หรือส่วนขยาย Python
วิธีแก้: ทำพาร์ท 1 และพาร์ท 2 แล้วปิดเปิด VS Code ใหม่

อาการ: ขึ้น NameError: name 'show_row' is not defined
สาเหตุ: ยังไม่ได้กด Run All หลังเปิดไฟล์ โมเดลจึงยังไม่ถูกสร้าง
วิธีแก้: กด Run All หนึ่งครั้ง แล้วลองใหม่

อาการ: แถบด้านบนขึ้นว่า Restricted Mode และรันไม่ได้
สาเหตุ: ยังไม่ได้กดเชื่อถือโฟลเดอร์
